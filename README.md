# Shiro Book Store — Static HTML Practice

A beginner-friendly static bookstore webpage with sections for book categories, services, and contact details.

Open `index.html` in a browser. Local JPG/JPEG assets are referenced from the project folder.

This is **a static classroom-style exercise**, not an operational bookstore or online commerce system. No checkout, inventory management, or account functionality is included. Image licenses have not been reviewed; verify rights before reusing them publicly.

For job applications, highlight more complete projects such as ResolveDesk instead.
